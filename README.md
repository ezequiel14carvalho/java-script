### 1. Counter Program
Um contador interativo simples e intuitivo.
* **Funcionalidades:** Permite incrementar, decrementar ou resetar o valor numérico central.
* **Link para testar:** [Acessar Counter Program](https://ezequiel14carvalho.github.io/java-script/counter-program/)

### 2. Temperature Conversion
Um conversor de unidades de temperatura rápido e funcional.
* **Funcionalidades:** Converte valores numéricos de Celsius para Fahrenheit e de Fahrenheit para Celsius.
* **Link para testar:** [Acessar Temperature Conversion](https://ezequiel14carvalho.github.io/java-script/temperature-conversion/)

### 3. Roller Dice
Um simulador gráfico para rolagem de múltiplos dados simultâneos.
* **Funcionalidades:** Sorteia valores numéricos aleatórios de 1 a 6 com base na quantidade escolhida e renderiza as imagens correspondentes de cada face do dado na tela.
* **Link para testar:** [Acessar Roller Dice](https://ezequiel14carvalho.github.io/java-script/dice-roller/)
